# THE BOARD

A private corkboard for current true-crime cases, Court TV headlines, and notes.

Repo: [wefeltlikeit-sketch/TrueCrimeStories](https://github.com/wefeltlikeit-sketch/TrueCrimeStories)

Unofficial personal tracker. Not affiliated with Court TV, any court, or any party. Accused persons are presumed innocent. Not legal advice.

## Use it

Connect this repo to Netlify (publish directory `.`, no build command) or open `index.html` locally.

- **Board** — drag folders, double-click a file, tie red string from the dossier
- **Docket** — filter the list
- **Wire** — tries Court TV RSS; falls back to a Sept 2026 clipping pack
- **Notebook** — sticky notes in this browser only (`localStorage` key `the-board/v1`)

Export / import JSON is in Settings.
